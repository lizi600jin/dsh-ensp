
# dsh-ensp

面向华为 eNSP 的自动化工具：生成拓扑、启动设备、逐条下发配置，并在每条命令后核对结果。

- 生成 eNSP 可直接打开的 `.topo` 文件，可用场景蓝图（含设备、链路、地址规划）或自定义设备与连线
- 自动定位工具栏按钮完成设备启停，启动后按设备逐一确认就绪，随后最小化窗口
- 逐条下发配置，任一命令出错即中断，并回报行号、命令与设备原始输出
- 内置 50 个场景预设，覆盖 VLAN、STP、堆叠、链路聚合、路由、BGP、MPLS、组播、NAT、ACL、QoS、IPsec、IPv6、WLAN、防火墙与高可用等主题
- 启动前检查机型镜像是否齐全，缺镜像时说明缺失组件，避免 eNSP 打开后静默退出
- 提供七项环境自检（镜像、端口、内存、输入注入能力），逐条给出结论与修法；配置下发后按场景断言验收
- 需要以管理员身份运行，并保持 eNSP 窗口可见（详见仓库文档“运行权限”）
- 提供 CLI、MCP Server 与 DeepSeek Harness 插件三种调用方式

向下翻页后点击“包含的组件”内的“dsh-ensp>”进入设置界面。
